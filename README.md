# 개발지식 강의 예제

개발자 팀의 개발지식 강의에서 사용하는 자바·스프링 샘플 코드입니다.

강의별 폴더에서 영상에 나온 코드를 확인하고 직접 실행할 수 있습니다. 각 강의의 README에는 필요한 도구와 버전, 실행 명령, 예상 결과, 주요 소스 파일을 안내합니다. 코드를 실행하지 않고 영상을 보셔도 설명을 따라갈 수 있도록 구성합니다.

강의 코드는 `lessons/날짜_주제명/`에 보관합니다. 강의에 여러 예제가 있으면 해당 프로젝트 안에서 예제별로 구분합니다. 실행 방법은 선택한 강의 폴더의 README를 참고해 주세요.
